結構：
  古詩詞網站/
    README.txt
    docs/                 ← 將成個 docs 內容用作 GitHub Pages（Settings → Pages → Folder: /docs）
      index.html          ← 入口

      《題西林壁》互動遊戲.html

上傳步驟：
1. 喺 GitHub 開新 Public repo（例如 gushi-ci）
2. 上傳「古詩詞網站」入面所有檔案（要有 docs 資料夾）
3. Settings → Pages → Deploy from a branch → main → /docs → Save
4. 網址：https://你的帳號.github.io/repo名/

本地測試：打開 docs\index.html

注意：入口按鈕已改為相對路徑；二維碼相關網上連結保留未改。
